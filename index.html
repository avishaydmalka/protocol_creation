האפליקציה נפתחה כקובץ מהמחשב. כדי שההקלטה וחיבור Google יעבדו, צריך להעלות אותה לכתובת אינטרנט (https). ההוראות בקובץ README שקיבלתם יחד איתה.

הגדרה ראשונה

שני צעדים, פעם אחת בלבד. המפתחות נשמרים רק בדפדפן הזה ולא נשלחים לשום מקום אחר.

  1. מפתח ל-Gemini
  2. חיבור ל-Google Docs

מפתח חינמי ל-Gemini

Gemini הוא המודל של Google שמאזין להקלטה וכותב את הפרוטוקול. המפתח חינמי ולא דורש כרטיס אשראי.

  1. פתחו את Google AI Studio והתחברו עם חשבון Google.
  2. לחצו Create API key. אם תתבקשו, בחרו פרויקט קיים או צרו חדש.
  3. העתיקו את המפתח שנוצר והדביקו אותו כאן.
פתיחת AI Studio

במסלול החינמי Google רשאית להשתמש בתוכן שנשלח כדי לשפר את המוצרים שלה. לישיבות רגישות אפשר להפעיל חיוב בפרויקט ב-AI Studio. העלות לישיבה היא אגורות, והתוכן לא משמש לשיפור המודלים.

חיבור ל-Google Docs

כדי שהפרוטוקולים יישמרו כמסמכים בחשבון Google שלכם צריך מזהה חיבור (Client ID). זה לוקח כעשר דקות, פעם אחת. אפשר גם לדלג ולחבר אחר כך מההגדרות.

  1. היכנסו ל-Google Cloud Console וצרו פרויקט חדש, למשל "פרוטוקולים".
  2. הפעילו בפרויקט את Google Drive API (כפתור Enable).
  3. עברו ל-Google Auth Platform ולחצו Get started: שם לאפליקציה, המייל שלכם, וסוג משתמשים External.
  4. בלשונית Audience הוסיפו את כתובת ה-Gmail שלכם תחת Test users.
  5. בלשונית Clients לחצו Create client, בחרו Web application, ותחת Authorized JavaScript origins הוסיפו את הכתובת הזו:
  6. העתיקו את ה-Client ID (מסתיים ב-apps.googleusercontent.com) והדביקו כאן.

האפליקציה מקבלת גישה רק לקבצים שהיא עצמה יוצרת ב-Drive, לא לשאר הקבצים שלכם. בהתחברות הראשונה Google תציג אזהרה שהאפליקציה לא אומתה. זה צפוי, כי זו אפליקציה פרטית שלכם: לחצו Continue.

ההקלטה

הודעה קולית מוואטסאפ: לחיצה ארוכה על ההודעה, שיתוף, שמירה בקבצים, ואז בוחרים אותה כאן. הקלטה מקומית של זום נשמרת במחשב בתיקייה Documents/Zoom.

מקליט את מה שנשמע בחדר דרך המיקרופון של המכשיר. מתאים לישיבה פרונטלית, או לזום בטלפון כשהשיחה ברמקול.

  1. פתחו את הישיבה בזום. הכי פשוט: זום בדפדפן Chrome, בלשונית נפרדת.
  2. לחצו "התחלת הקלטה". בחלון השיתוף שייפתח בחרו את לשונית הזום וסמנו שיתוף אודיו של הכרטיסייה. אם זום פתוח כאפליקציה במחשב Windows, בחרו מסך מלא וסמנו שיתוף אודיו של המערכת.
  3. המיקרופון שלכם מוקלט בנפרד, כך שגם הקול שלכם ייכנס לפרוטוקול. עדיף להשתמש באוזניות, כדי שלא יהיה הד.

ב-Mac, שיתוף אודיו של המסך כולו נתמך רק בגרסאות חדשות. אם האפשרות לא מופיעה, פתחו את זום בדפדפן.

הקלטת ישיבת זום זמינה במחשב, בדפדפן Chrome או Edge. בטלפון אפשר להקליט במיקרופון כשהזום ברמקול, או להעלות אחר כך את קובץ ההקלטה של זום.
